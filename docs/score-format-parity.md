# Scoreboard format consumers and native backgrounds

2026-11-15. Protocol-766 objective and score packets now convert their optional blank/styled/fixed number formats into renderable values. Scoreboard state retains objective defaults, per-score overrides and optional display components separately from numeric scores. Updates/reset packets clear the corresponding text/format state; numeric values still control sorting. Sidebar and tab-list number rendering use the same effective format path. Native custom display components receive the entry owner's team decoration without treating the plain owner name as a JSON component.

Blank/fixed-empty scores reserve no numeric/colon width. Modern sidebar rows sort descending by value with case-insensitive name ties and keep the first 15 visible owners. Empty objectives still draw the native header. Coordinates use integer GUI division. The native accessibility background value replaces the default opacity rather than multiplying it.

`ExtractScoreFormats1206.java` runs actual NumberFormat/PlayerScoreEntry methods and writes actual score/objective stream-codec packets. **28 native cases** cover default, blank, styled (including font/style flags) and fixed formats at zero, negative and maximum values. Seven consumer tests cover those packet bytes/components, defaults/clears, actual sidebar/tab-list drawing, hidden entries, empty widths and empty-objective backgrounds. Two further tests exercise Options.getBackgroundColor behavior and the real sidebar. The complete target gate passes **473 tests** with no failures/skips. Browser bundles pass; no native graphical/GPU metrics are claimed.

Native sources: 1.20.6 Gui (`fgs`), PlayerTabOverlay (`fih`), NumberFormat implementations (`zd`, `ze`, `zi`), PlayerScoreEntry and ReadOnlyScoreInfo, ClientboundSetScorePacket and ClientboundSetObjectivePacket. All oracle classes are byte-verified against the pinned client jar. [Official 1.20.3 notes](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-20-3) and [versioned Wiki history](https://minecraft.wiki/w/Java_Edition_1.20.3) place custom number formats/display names after all supported older branches. Those fields and the newer empty-header arrangement are not backported. Native DisplaySlot names also correct the 1.20.2 rename to `below_name`; parser choices/suggestions are tested against the actual 1.20.6 enum. The seven older Brigadier clients gain missing slot suggestions while retaining `belowName` (seven additional integration checks).

The background-opacity correction applies from 1.14.4. Native Gui anchors: `cyv`, `dci`, `dkv`, `dwm`, `dzq`, `enq`, then `fgs`. Six older branches pass **12 related tests** and browser bundling. 1.8.9/1.12.2/1.13.2 retain their older fixed colors and layouts. No distribution rebuild is included.

Remaining scoreboard parity includes below-name labels, tab-list hearts/blink behavior and broader native-font/live/backend acceptance. These gaps are explicit in CHAT-02; formatted sidebar/list implementation is recorded separately as completed. This batch does not certify full client parity.
