# Command input and debug tags

The native 1.13.2 client now decodes Declare Commands and all three registries in
Tags. F3 lists every synchronized block/fluid tag, after the block's state
properties. Sand therefore shows `#minecraft:enderman_holdable` and
`#minecraft:sand`. Server reloads replace memberships rather than accumulating
stale tags. Disconnect/reset clears the server tree and memberships. Vanilla
fallback tags, including nested memberships, are generated from the pinned jar
by `node tools/extract-tags.mjs --write` (`--check` verifies them).

Chat and command-block input use the server's permission-filtered Brigadier tree.
Parsed arguments use aqua/yellow/green/light-purple/gold, literals use gray, and
unread syntax errors use red. Local validation covers primitive bounds, resource
identities, block-state properties, coordinate groups, ranges and basic selectors;
server execution remains authoritative. Complex selector options, SNBT semantics,
and some argument-specific suggestions still need parity work. This is not a
claim of complete Brigadier parity.

Known local suggestions open while typing slash commands. Dynamic providers use
transaction-checked server requests. Tab cycles, Shift+Tab reverses, arrows move
selection, and the browser wheel scrolls a hovered list in the correct direction.
Ordinary chat opens player-name suggestions only on Tab, including an empty input.
Accepting a suggestion preserves text after the cursor. Command blocks share the
input path without requiring a slash or using chat history.

The 1.12.2 and 1.8.9 backports fix suffix loss and stale replies in their existing
server-driven Tab completion. They retain their version's completion UI and wire
format. Tags and the Brigadier UI were introduced in 1.13 and are not backported.

Validation includes a real 755-node packet and 20 parse examples generated by the
pinned vanilla client/Brigadier, tag wire replacement and F3 output, formatter
cursor preservation, local/dynamic suggestions, player names, scrolling and
command-block input. The vanilla component reader's occasional one-past-end
range is clamped for display. All version builds and existing suites are checked.
