# 1.19.4 development checkpoint

The graphical client now identifies as **1.19.4 / protocol 762**, loads native
1.19.4 assets, and joins a native offline-mode server. Full parity is unfinished.
The eight older published clients remain separate targets.

## Implemented and checked

- Pinned official jars, mappings, asset index and protocol inputs; native reports
  contain 998 blocks and 23,725 block states. Native collision, selection,
  occlusion, render layers, sounds, metadata, creative tabs and GUI option arrays
  are extracted rather than copied from a newer release.
- 762 login/respawn/dimensions, terrain/light, unified entity spawning, metadata,
  bundles, player lists, commands/recipes, sound holders, particles, block entity
  records and sequence-based block prediction. Unknown packets remain explicit.
- Native JOML model extraction, including the changed vex, new Wild Update mobs,
  and the full native boat/chest-boat type ordering. Keyframe interpolation is
  checked against 52 poses generated by Minecraft's Java animation code.
- Native creative categories and operator tab permissions; separate Controls and
  Key Binds screens; native accessibility/chat/video option ordering. Browser-only
  capabilities are reported honestly (monitor resolution is unavailable).
- Font `space` providers and native glint asset names. Darkness effect, recovery
  compass and goat horn timing have initial implementations; these are not a
  claim of full visual or sound parity.
- Gray grass fix: extract native climate values missing from the source biome
  table. Send server biome registries to all meshing workers and honor explicit
  grass/foliage colors. The worker/color fixes also apply to 1.16.5–1.18.2.
- New damage events invoke hurt sounds, including the damage registry's player
  effect-specific sounds; the separate hurt-animation packet does not play a
  duplicate sound. Checked against LivingEntity, Player and DamageEffects native
  methods (`bfx`, `bym`, `bek`) and the damage packet (`wd`).

## Stable content versus experiments

Cherry, bamboo wood/rafts, camels, sniffers, archaeology and armor trims are
**1.20 experimental content in the 1.19.4 jar**, not normal 1.19.4 content. Native
registry IDs and model definitions must remain intact for decoding. Normal and
operator creative catalogs are extracted with `FeatureFlags.VANILLA_SET`; tests
assert experimental items stay absent. Enabling a server's experimental creative
catalog is still pending. None of these features is backported to older targets.

References: [historical 1.19.4 Wiki](https://minecraft.wiki/w/Java_Edition_1.19.4),
[Cherry history](https://minecraft.wiki/w/Cherry), and
[Mojang's 1.19.4 release notes](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-19-4).
The pinned exact native code determines layouts, registry order and packet bodies.

## Reproduction

```sh
node tools/port-1.19.4/prepare.mjs
node tools/port-1.19.4/reports.mjs --check
node tools/port-1.19.4/runtime-data.mjs
npm run assets
node tools/port-1.19.4/verify-protocol.mjs
node --test tools/test-biome-worker-colors.mjs tools/test-damage-1194.mjs tools/test-experimental-gating-1194.mjs tools/test-native-keyframes-1194.mjs tools/test-projectile-rendering.mjs tools/test-controls-pages.mjs
node tools/port-1.19.4/probe-server.mjs --port=25567 --duration=25000
# Only on the isolated fixture with its operator test account:
node tools/port-1.19.4/probe-server.mjs --port=25567 --duration=22000 --fixture-damage=true
```

Runtime finalization regenerates animations and Java pose expectations too. CFR
is required to extract native GUI layouts; extraction fails if unavailable.
The terrain probe observed 461 chunks / 11,064 sections. A Chromium graphical
probe joined, rendered terrain/entities and opened the native option pages and
creative tabs. These are observations, not a graphics performance benchmark. The isolated native server also emitted
all six damage-effect sounds through the decoded packet/handler pipeline
(generic, burning, drowning, freezing, berry bush and thorns), with health
updates and a keepalive round trip. This verifies sound selection/dispatch;
headless Chromium did not establish audible playback on a physical device.

ports; it is not reported as passing. Targeted tests and live checks above do
not establish that every feature is correct.
