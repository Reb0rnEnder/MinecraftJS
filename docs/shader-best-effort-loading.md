# Shader best-effort loading — 2026-11-04

At the user's request, incomplete packs now load what can run instead of being rejected wholesale. This supersedes the preceding strict missing-attachment import policy. The shader screen says **Loaded with limitations** and its status tooltip lists the missing stages, compatibility settings and fallback inputs. Long tooltips are bounded to the screen.

The client compiles and executes the pack's own supported final/vegetation/post programs. A failed post stage is reported and skipped while earlier/later compatible stages remain available. If final cannot use this renderer's capabilities, it reports that failure and presents the existing scene; it does not generate replacement visual effects. Structural archive/include errors and unexpected failures still retain normal error handling. Missing 2D colour attachments may use the current scene colour, and depthtex1/2 may use captured scene depth, but **each fallback is explicitly reported**. Unknown uniforms, shadow maps, unsupported array/3D samplers, MRT outputs, formats and temporal inputs are not claimed as implemented.

These are attempts at partial compatibility, not visual parity. Full native BSL/Complementary/Photon sky, water, material/temporal buffers and shadow rendering remains unfinished. Generated MinecraftJS cloud/wave/lightmap replacements and their Extras switches stay removed. Native-only behavior stays independent of the optional shader pack.

Checks: 22 focused loader/options/stage/menu/depth/vegetation and GPU regressions pass on each of all nine targets. Original small GLSL fixtures verify pass order, numeric pixels, world overrides, disabled programs, a missing-input warning, skipping an unsupported nonzero attachment, continuing with a later real stage, and resource cleanup. The supplied BSL archive is attempted in all dimensions. Cached upstream Complementary/Photon and the supplied Sildur/Astra archives also load in best-effort mode with explicit limitations and no WebGL error in the smoke check. These tests do not establish full-pack image fidelity or desktop GPU performance.
