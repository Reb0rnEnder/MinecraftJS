# Resource-stack and pack metadata parity

2026-11-15. Resource packs now use one priority stack for direct files, sounds, translations and font definitions. Previously several consumers bypassed pack priority or read directly from the base assets. Native block/item models and textures now remove resources filtered by a higher pack, and PNG metadata is not inherited from below the pack supplying the PNG.

1.20.6 adds native format-selected overlay directories. Applicable entries are layered in declaration order (later wins); root pack.mcmeta/icon metadata remains in the primary pack. Namespace discovery, listing and direct reads all see overlay contents. Numeric, two-element and min_inclusive/max_inclusive ranges follow the native metadata codec, including native numeric conversion and invalid-section behavior. Overlay metadata is ignored in older targets.

1.19.4 and 1.20.6 gain resource filtering. Exact-version native fixtures establish that regex matching searches substrings, namespace/path predicates are independent (including the native cross-entry combination behavior), and filters suppress lower resources while preserving files supplied by their own pack. 1.19.4 lenient optional patterns turn malformed values into absent/any predicates; 1.20.6 rejects the malformed filter section. Older targets ignore filter metadata.

Sources: pinned jars/mappings for CompositePackResources, OverlayMetadataSection, ResourceFilterSection, ResourceLocationPattern, MultiPackResourceManager and FallbackResourceManager. `tools/ExtractPackMetadata.java` executes the actual metadata parsers and query methods: **30 cases on 1.20.6 and 12 on 1.19.4**. Native ResourceLocation normalization and texture-metadata ownership are retained. The [official 1.20.2 release notes](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-20-2) document overlays; [pack metadata history](https://minecraft.wiki/w/Pack.mcmeta) distinguishes later formats.

Shared backports cover all ten existing branches. They retain en_US.lang on 1.8.9, en_us.lang on 1.12.2, JSON languages on 1.13.2+, the older font-provider families, and the availability of villager metadata only from 1.14.4. Later GUI sprite scaling, reference/Unihex providers, overlays and filter metadata are not enabled in older releases. Direct reads stop as soon as the winning file is found, avoiding redundant lower-pack/network reads.

Checks cover real ZIP packs, overlay precedence and listing, root metadata, format rejection, own/lower filtered resources, namespaced direct reads, language/sound merging, model/texture removal, metadata ownership, and real bitmap-font provider layering. The resource suite plus related namespace/spacing checks pass **80 tests across the nine older branches**; all ten browser entrypoints bundle. The native-data gate and full 1.20.6 suite pass **451 tests**. GUI sprite fixtures now provide actual PNG bytes rather than an impossible has-file/returns-null mock.

Remaining: the full Java Pattern language (e.g. atomic/possessive constructs and unusual Unicode flags) is not certified by the JavaScript regex adapter; atlas JSON source dispatch/palette permutations remain PACK-02; broader live pack/backend lifecycle remains PACK-04. PACK-01 stays partial with completed implementation shown explicitly. No Java graphical run, GPU/FPS claim or distribution rebuild is included in this source batch.
