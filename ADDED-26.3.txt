5. PLAY PROTOCOL - OUTBOUND AND INTERACTION (P06/P08)
======================================================================

- Serverbound bodies rewritten from 26.3 bytecode: attack/interact, container close/click,
  creative slot, player action, use_item_on, accept_teleportation, movement flags,
  client_tick_end, keep_alive, pong, chat, command, recipe book, settings and related senders.
- All 69 serverbound IDs are accounted for by a real sender or a recorded scope decision; only the
  gametest block editor is scoped out.
- 26.3 chat uses chat / chat_command / chat_ack ids plus the LastSeenMessages checksum byte.
- Recipe-book add/remove/settings carry the native display graph; place_recipe and seen_recipe
  send RecipeDisplayId VarInts, and place_ghost_recipe resolves its RecipeDisplay into the grid
  ghost. See the native recipe-book paragraph below.
- Creative inventory carries the native raw component patch and native HashedStack hashes.
- writeHashedStack26_3 round-trips Mojang's own HashedStack encoder for all 405 patched Creative
  stacks. Server-decoded patches also keep each added component's exact wire bytes, so a normal
  container click writes the received patch back unchanged; a locally changed damage value
  replaces only its damage row. Component-patch stacking ignores transport bytes, and number-key
  swap now handles the off-hand button 40 (plus drag distribution, pickup-all and full-container
  shift-click coverage).
- Native menu registry mapping (26.3 menu order matches 766's 25 IDs).
- Local crafting for native shaped/shapeless recipes and {any:[item ids]} tag alternatives.
- The native RecipeDisplay graph is resolved into the book: all 13 recipe-book categories map to
  their tabs, SlotDisplay item/item_stack/tag/composite/remainder/fuel branches resolve to
  stacks, shaped width/height and empty cells are preserved, shapeless/furnace/stonecutter/
  smithing displays become grid records, and entry flags 1/2 drive notification/highlight.
  Native add/replace/remove rebuild the parsed book, settings drive the four book states, seen
  display ids stay seen across later adds, and the server ghost display drives the grid ghost.
  Pinned by tools/test-recipe-displays-26.3.mjs.
- Chat clickable styles are right-click only; shift-right-click applies style insertion, and
  clicked run_command actions use the unattended command packet with the optional slash trimmed.
  Suggestion rows apply from any mouse button, blank list clicks are consumed, and the existing
  hover/selection/wrap/ghost-text behavior stays aligned with CommandSuggestions. Pinned by
  tools/test-chat-click-actions-26.3.mjs.
- Crafting remainders read the native use_remainder component (milk bucket -> bucket).
- Live server accepted a pickup+place click (state 1 -> 2, dirt 43 -> 44, no resync); live attack
  removed a summoned pig after 8 hits; block break and place were server-verified.

Known limit:
- Canonical HashedPatchMap hashes for arbitrary server-provided component values are still not
  implemented. Integer-valued components (damage, max stack size, max damage, repair cost,
  ominous-bottle amplifier and enchantable) now use the pinned HashOps.CRC32C integer payload and
  match Mojang's values exactly, including predicted damage. Enchantment and stored-enchantment
  maps also use the native string/map HashOps encoding, verified against all 128 native catalogue
  maps. Other components without a known hash travel in an empty hash map; the server accepts the
  click and may resync the slot. A
  synthetic patch with no captured bytes and no native encoder still fails loudly rather than
  inventing a hash. Full no-resync parity needs the canonical per-component codec encoding.

13. WHAT THIS DOES NOT MEAN
======================================================================

- "137 payloads adapt" does not mean every adapted family has been live-triggered. Sounds,
  cooldowns, mob effects, boss bars, entity/world events and many presentation frames are
  byte-gated and socket-verified, not accepted in a live scenario.
- Native item components do not mean arbitrary runtime component values carry canonical
  HashedPatchMap hashes; server-decoded patch bytes are preserved, integer components and the
  Creative catalogue have exact hashes, but other unknown hashes use the empty-map resync fallback.
- Native entity rigs are structurally verified, not visually accepted.
- P09 authenticated lifecycle/transfer/packs, P11 new-content acceptance, P14 inherited 1.20.6
  findings, P15 whole-target acceptance and P16 packaging are not done.
- Full visual acceptance has not been performed for every screen, particle, animation or mob.
